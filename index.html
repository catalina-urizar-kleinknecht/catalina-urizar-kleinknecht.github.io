B.Sc. Thesis · RWTH Aachen · Graded 1.0
Aluminium distribution in zeolites

Machine-learning-driven analysis of the aluminium distribution in zeolites (H⁺ as cation) using pretrained machine-learning potentials in automated, large-scale simulation workflows. I designed the search algorithm, a Monte Carlo / Basin Hopping scheme combining local and global swaps with local and global relaxation, and tuned its hyperparameters for result quality, convergence and running time.

Results were validated against DFT calculations and published literature. The research group still uses the code to run further simulations for a paper in preparation.

05 — Engineering Approach

I value maintainability over unnecessary complexity. I prefer clear boundaries between data access, business logic and presentation, and I design systems so that infrastructure decisions can evolve without rewriting the application.

My approach emphasizes validation, reproducibility, testing and pragmatic architecture, especially when working with existing systems, physical models or imperfect data.
